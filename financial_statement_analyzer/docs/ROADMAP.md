# Suggested Roadmap

## Phase 1 — MVP
PDF upload, extraction, manual validation, trend chart and CSV export.

## Phase 2 — Reliability
- Add OCR for scanned reports
- Add source-page references and extraction confidence
- Add currency and unit normalization
- Create a curated benchmark dataset and automated tests

## Phase 3 — AI assistance
- Add optional LLM extraction with schema validation
- Compare extracted values against deterministic checks
- Add analyst feedback capture and audit history
